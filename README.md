# Date Difference Calculator

A simple, free and privacy-friendly web tool to calculate the difference between two dates.

## Features

- Runs directly in the browser
- No account required
- No server-side storage
- Lightweight static web app
- Easy to deploy on Cloudflare Pages

## Privacy

This tool is designed to work client-side. Data entered by the user is not intentionally sent to external servers.
